# IntentGate

IntentGate is a dependency-free control plane for treating model-generated
business actions as untrusted proposals. A deterministic policy gate,
role-specific human approval, expiry checks, replay prevention, and an
independent verifier stand between a proposal and a committed effect.

The checked-in fixture is synthetic. It contains no real employee data and
supports no model-quality, legal-compliance, production-IAM, or safety-
certification claim.

Development evidence and full documentation are being assembled on the
portfolio branch.
